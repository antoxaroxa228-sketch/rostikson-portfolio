# Ростиксон — портфолио контент-создателя

Одностраничный адаптивный сайт для брендов, ресторанов и маркетплейсов.

- реальное фото в hero;
- встроенные Instagram Reels для ресторанов и ВкусВилла;
- 700+ обзоров, 50+ млн ₽ в заказах, 3000+ реклам;
- 20+ человек в команде и 6 лет в медийке;
- кейс квартиры на YouTube;
- адаптация под desktop/mobile;
- без API-ключей, базы данных и серверной части.
