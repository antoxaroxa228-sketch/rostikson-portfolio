# Ростиксон — портфолио контент-создателя

Одностраничный адаптивный сайт для брендов, ресторанов и маркетплейсов.

- статический HTML/CSS/JS;
- deploy-ready для Vercel;
- настоящие фотографии заказчика;
- короткие локальные video-preview;
- длинный кейс квартиры открывается на YouTube;
- мобильная адаптация;
- без API-ключей и серверной части.

Подробный деплой: [`README_DEPLOY.md`](./README_DEPLOY.md).
